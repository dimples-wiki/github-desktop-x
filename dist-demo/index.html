架构要点（供人工复核）

  • 上游仓库零功能改动：只含扩展点（patch 0001–0008 全部可审计，patches/）
  • Commits 筛选与 Changes Tree 视图均为运行时动态加载插件（plugins/，esbuild IIFE，经 IPC 下发 renderer eval）；删除插件目录即回到原生行为
  • 插件 UI 复用宿主原生类名/组件（.header .filter-field-row、ChangedFile、filter-popover），保证与原生像素一致
  • 源码位于本机 ~/github-desktop-x：构建 scripts/package-release.sh、验收 scripts/launch-error-scan.ts / scripts/gui/capture-evidence.js、像素对比 scripts/measure-*.ts
